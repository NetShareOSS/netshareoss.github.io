# Download Netshare for Mac

Get the notarized DMG for direct install, or install from the Mac App Store.

## Download

- Download .dmg — URL is read from [`/assets/downloads/macos-dmg.url`](https://netfshare.site/assets/downloads/macos-dmg.url) (paste the Cloudflare Worker DMG URL there after deploy; not a public `r2.dev` link)
- [Mac App Store](https://apps.apple.com/vn/app/id6758239332)

## How to install from the DMG

1. Open the downloaded **NetShare.dmg** file.
2. Drag **NetShare** into the Applications folder.
3. Open NetShare from Applications (or Launchpad).

The DMG is Developer ID signed and notarized by Apple, so Gatekeeper should accept it without extra steps.
